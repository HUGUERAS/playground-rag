# GeoAdmin Docs

Esta pasta consolida a documentacao oficial do projeto `GeoAdmin`.

## Precedencia editorial

1. O pacote `.zip` fornecido pelo usuario e a fonte oficial desta base.
2. O arquivo `Google_Gemini_source.html` fica arquivado apenas como trilha historica e contexto complementar.
3. As capturas de tela fornecidas na conversa validam nomes, agrupamentos e comportamento funcional do app.

## Estrutura

- `01-product`: PRD e visao do produto.
- `02-planning`: roadmap, fases e backlog orientado a entrega.
- `03-functional-mapping`: mapeamento da interface real para modulos e backlog.
- `04-reference`: comandos, regras operacionais, formulas e blindagem.
- `05-source-archive`: fontes brutas e indice de origem.
- `06-governance`: fluxo editorial, backlog documental e criterios de pronto.

## Como usar

- Comece por `01-product/PRD_GeoAdmin.md` para entender o sistema.
- Leia `02-planning/Master_Plan_v2_GeoAdmin.md` como referencia principal de execucao.
- Consulte `02-planning/Roadmap_GeoAdmin.md` apenas como plano legado e mais resumido.
- Consulte `03-functional-mapping/App_Functional_Mapping.md` para relacionar telas, modulos e gaps.
- Use `04-reference` como material operacional de apoio.
- Use `06-governance` para manter a documentacao consistente antes de abrir novas frentes de codigo.

## Ordem de trabalho recomendada

1. Consolidar requisitos e linguagem em `01-product`.
2. Transformar features observadas em backlog claro em `02-planning` e `03-functional-mapping`.
3. Fixar regras, formulas e validacoes em `04-reference`.
4. Registrar pendencias, decisoes e criterio de pronto em `06-governance`.
