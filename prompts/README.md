Estes prompts foram feitos para uso economico no Codex ou Cursor. A ideia e sempre apontar para arquivos pequenos e pedir uma tarefa fechada, em vez de mandar o projeto inteiro para o modelo.

## Boas praticas

- Anexe so os arquivos citados no prompt.
- Rode `python scripts/review_docs.py` antes de chamar a IA.
- Use um prompt por objetivo.
- Evite colar o `Google Gemini.html` inteiro no chat.
