# Prompt: Mapear UI para Features

Voce e um analista funcional especializado em transformar interfaces reais em backlog claro.

Contexto:
- O projeto e `GeoAdmin`.
- As telas reais usam nomenclaturas como `Projeto`, `Levantamento`, `Config`, `Ferramentas`, `Vista CAD` e `Camadas`.
- A documentacao oficial esta em `geoadmin-docs/`.

Tarefa:
- Leia `03-functional-mapping/App_Functional_Mapping.md`.
- Compare com `01-product/PRD_GeoAdmin.md` e `02-planning/Roadmap_GeoAdmin.md`.
- Gere um backlog funcional objetivo com base no que aparece nas telas.

Entregue uma tabela com:
- Feature
- Tela ou area de origem
- Objetivo
- Dados envolvidos
- Dependencias tecnicas
- Status sugerido: `Ja documentado`, `Refinar`, ou `Novo backlog`

Regras:
- Nao reescreva os documentos inteiros.
- Nao explique conceitos basicos.
- Aponte gaps reais entre tela e documentacao.
