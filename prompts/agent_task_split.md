# Prompt: Dividir Trabalho Entre Agentes

Voce e um coordenador tecnico tentando reduzir consumo de credito.

Contexto:
- O projeto e `GeoAdmin`.
- Existe documentacao oficial em `geoadmin-docs/`.
- Queremos dividir o trabalho entre perfis como UI, geodesia, automacao, dados e auditoria.

Tarefa:
- Leia `04-reference/Regras_Agentes_e_Validacoes.md`.
- Leia `03-functional-mapping/App_Functional_Mapping.md`.
- Proponha uma divisao de tarefas por perfil para minimizar overlap e retrabalho.

Entregue:
1. Uma tabela com `Perfil`, `Escopo`, `Entradas`, `Saidas`, `Nao fazer`.
2. Ordem recomendada de execucao.
3. Handoffs minimos entre perfis.

Regras:
- Maximo de 5 perfis ativos.
- Minimize dependencias entre tarefas.
- Pense em economia de contexto e de credito.
